# 所有操作以「向」为基准

度数输入、滑杆、点山、八方按钮、方向键和分享链接里的度数，指的都是**向**（天心十道纵线上方所对的山与度数），不是坐。按「北」得到的是坐午向子，不是坐北朝南。这样定，是因为指南针模式读到的就是手机顶端所指的方向（向），手动模式也照同一个基准，两边不用换算；读数条会同时显示向度和坐度。

## Considered Options

- **以坐为准**：比较接近「坐北朝南」「坐子向午」的说法，但指南针模式量到的是向度，每种操作都要换算。没有采用。
- **混用**（数字按向，点山和八方按坐）：同一个画面上两种基准，容易搞混。没有采用。

## Consequences

分享链接 `?d=` 里的值是向度。以后若改成以坐为准，所有已经分享出去的链接都会差 180°，所以不能直接改，必须另外换一个参数名。
