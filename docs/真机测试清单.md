# 真机测试清单

指南针模式、权限、屏幕常亮、安装和离线这些功能在模拟器里测不了，要在真机上逐项检查。用 `npm run dev:phone` 扫码打开，或者用 Vercel 的网址。

每项都在 **iPhone（Safari）** 和 **Android（Chrome）** 上各测一次；标「已安装」的项目，要在加到主屏幕后、从主屏幕打开时再测一次。

## 画面

- [ ] 第一次打开显示「坐子向午」，向 180.0°，「向」标签在上
- [ ] 刘海和底部横条不会挡住罗盘或按钮
- [ ] 深色模式下文字看得清，罗盘外观不变
- [ ] 横放手机（未安装时）：罗盘在左，读数和面板在右

## 手动操作

- [ ] 拖动盘面时跟着手指走，放开后停在原处，不会自动对齐
- [ ] 点二十四山、后天八卦、八方中的任一格，那一格的中线会转到天心十道上方（向）
- [ ] 滑杆、−1° / +1° 都正常
- [ ] 点度数输入框时出现数字键盘，并且有小数点
- [ ] 读数接近交界时出现大空亡或小空亡提示，例如向 202° 显示「大空亡（癸丑之交）」

## 指南针模式

- [ ] 按「开启指南针」：iPhone 会弹出权限请求，选「允许」后开始跟随
- [ ] 平放手机，和手机自带的指南针 App 比对：向度相差在几度之内
- [ ] 手机顶端朝北时向度接近 0°（坐午向子）；原地向右转，向度增加，盘面往左转
- [ ] 手机倾斜超过约 20° 时显示「请平放手机」，读数变灰；放平后恢复
- [ ] 「锁定读数」之后转动手机，读数不变；解锁后继续跟随
- [ ] 开着指南针 1–2 分钟，屏幕不会自动熄灭；退出后恢复平常的熄屏时间
- [ ] 开着指南针时拖动盘面，会提示「已退出指南针模式」并回到手动操作
- [ ] iPhone：精度一栏会显示 ±度数；把手机靠近磁铁或喇叭时，精度会变差或提示校准
- [ ] Android：第一次开启时显示「画 8 字」的校准说明，之后不再出现
- [ ] 拒绝权限后显示重新允许的方法，「再试一次」按钮有效

## 寻方

- [ ] 刚打开、还没开指南针时直接按「东南」：iPhone 会弹出权限请求，选「允许」后开始跟随，「东南」按钮变蓝
- [ ] 平放手机：盘面上的蓝色箭头指向的方向，和手机自带指南针 App 的东南（约 135°）一致
- [ ] 原地慢慢转身，蓝色指引里的「向右转 / 向左转」度数跟着变小；转到手机顶端朝东南时显示「✓ 正对东南」
- [ ] 换按「北」，蓝色箭头改指北方；再按一次「北」，箭头和指引消失，仍在指南针模式
- [ ] 锁定读数后再按任一方位，会自动解锁、继续跟随
- [ ] 按九宫格正中的「退出指南针」后回到手动操作，八方按钮都不再是蓝色

## 安装与离线

- [ ] iPhone Safari：第一次打开时底部显示「加入主屏幕」提示，关掉后不再出现
- [ ] Android Chrome：「操作」页底部出现「安装到主屏幕」，安装后从主屏幕打开没有网址栏
- [ ] 已安装（Android）：固定竖屏，手机平放时画面不会突然转成横屏
- [ ] 已安装（iPhone）：记录每次从主屏幕打开时，是否都要重新允许方位权限
- [ ] 打开过一次后开飞行模式，再从主屏幕或书签打开，仍然能用
- [ ] 关掉再重新打开，度数还原成上次手动设的值

## 分享

- [ ] 按分享按钮：手机上出现系统分享面板，内容是坐向文字加链接
- [ ] 在另一台设备上打开链接，显示同一个坐向；打开后网址里的 `?d=` 被去掉
